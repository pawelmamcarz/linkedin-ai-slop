Plans

LinkedIn only. The extension is free. Hosted Pro is the only paid tier, and it starts only after Stripe keys are set on the proxy.

Free / BYOK

You run server/ and put your own TYPESAFE_API_KEY in server/.env. In the extension options pick BYOK and the proxy URL. The key never enters the extension. This mode is live.

Hosted Demo

The default URL https://proxy-production-ebcc.up.railway.app is a public demo, not a paid plan. The per-minute cap is about 60 scores per IP. The daily brake is in the code: DEMO_MODE=1 means 40 scores per day when EVALUATE_DAILY_IP_CAP is unset. On Railway that brake applies only after the variable is set. Leave DEMO_MODE unset for local BYOK.

Hosted Pro

Price: from about 5 USD per month or about 40 USD per year. A one-time price around 9–19 USD is a fair way to describe it, but Checkout sells a monthly or yearly subscription, not a one-time charge.

After payment the proxy shows a Pro token. Paste it in options (Pro mode). The extension sends X-Pro-Token. That is not the TypeSafe key. Pro has higher limits (300 per minute and 2000 per day per IP by default).

The token gate is in the code. Checkout on the live proxy turns on only when Railway has STRIPE_SECRET_KEY and STRIPE_PRICE_MONTHLY or STRIPE_PRICE_YEARLY. Without those, the links below return a “coming soon” page and point at GitHub.

Checkout: about 5 USD / month Checkout: about 40 USD / year

If Checkout is not configured, write via GitHub Issues.
