LinkedIn AI Slop

Rozszerzenie do Chrome i Edge. Przy scrollowaniu feedu LinkedIn na karcie pojawia się odznaka.

  • Ludzki
  • Mieszany
  • AI slop

Co to jest

Gdy post wejdzie w widok (około 35% wysokości kadru), rozszerzenie wyciąga jego tekst i prosi o ocenę. Odznaka ląduje w prawym górnym rogu karty. Komentarze pod postem są pomijane, a tekst krótszy niż 40 znaków w ogóle nie wychodzi z przeglądarki.

TypeSafe Jev

Ocena idzie przez TypeSafe Jev API: POST https://api.typesafe.ai/v1/systemone, model jev-latest. Jedno wywołanie na post, cztery pytania: is_ai_slop, slop_intensity, has_substance, voice.

Kolor odznaki liczy kod w repozytorium (jev/thresholds.ts), nie ta strona. Domyślny próg is_ai_slop to 0.65.

Instalacja z repozytorium

Rozszerzenia nie ma w Chrome Web Store. Ładuje się je z GitHuba.

  1. Sklonuj albo pobierz github.com/pawelmamcarz/linkedin-ai-slop.
  2. Otwórz chrome://extensions (w Edge: edge://extensions) i włącz tryb dewelopera.
  3. Wybierz Załaduj rozpakowane i wskaż katalog extension/.
  4. W opcjach rozszerzenia włącz ocenę. Domyślny adres proxy to http://127.0.0.1:8787. Przycisk Sprawdź proxy powinien pokazać model jev-latest.

Proxy zostaje u Ciebie

Node trzyma TYPESAFE_API_KEY i woła Jev. Uruchamiasz je lokalnie (cd server, potem npm install i npm start) albo na innym hoście, który sam prowadzisz. GitHub Pages serwuje tylko pliki z docs/. Nie ma tu procesu Node, nie ma klucza i ta strona sama nie woła TypeSafe.
