Hostowane proxy to publiczne demo z limitem. Do codziennej pracy postaw własne proxy i własny klucz (BYOK). Sklep Chrome jeszcze nie jest źródłem instalacji. Ta sama paczka zip działa w Chrome, Brave i Edge. Safari to osobny build na Macu (niepodpisane rozszerzenie deweloperskie), bez App Store. Produkt działa tylko na LinkedIn.

Jak to działa

1. Widoczny post

Gdy karta wejdzie w widok (około 35% wysokości), rozszerzenie bierze tekst posta. Komentarze pomija. Tekst krótszy niż 40 znaków zostaje w przeglądarce.

2. Jev na proxy

Jedno wywołanie na post: model jev-latest, pytania is_ai_slop, slop_intensity, has_substance, voice. Próg domyślny to 0.65.

3. Odznaka

Kolor liczy kod w repozytorium, nie ta strona. Najedź na odznakę, żeby zobaczyć prawdopodobieństwa.

Instalacja

Chrome i Edge

  1. Pobierz repozytorium albo rozpakuj store/linkedin-ai-slop-extension.zip.
  2. Otwórz chrome://extensions albo edge://extensions i włącz tryb dewelopera.
  3. Załaduj rozpakowane i wskaż katalog extension/.

Sklep Chrome jeszcze nie publikuje tej pozycji. Zip odtwarzasz przez npm run pack:extension.

Brave

Ta sama paczka Chromium. Osobnego pliku Brave nie ma.

  1. Otwórz brave://extensions i włącz tryb dewelopera.
  2. Załaduj rozpakowane i wskaż extension/.
  3. Gdy sklep Chrome ruszy, Brave umie wziąć stamtąd ten sam wpis. Dziś go nie ma.

Notatka: store/BRAVE.md.

Safari

Projekt Xcode w safari/. Na Macu: bash scripts/build-safari.sh. To nie jest App Store ani TestFlight.

  1. Safari → Develop → Allow Unsigned Extensions.
  2. Uruchom aplikację z Xcode, włącz rozszerzenie i zezwól na www.linkedin.com.

Notatka: store/SAFARI.md.

Proxy demo i własny klucz

Publiczne demo

https://proxy-production-ebcc.up.railway.app

Klucz TYPESAFE_API_KEY zostaje na serwerze. Ta strona go nie ma i sama nie woła TypeSafe. GitHub Pages serwuje tylko docs/.

Limit: 60 żądań na minutę z jednego adresu IP. Powtórzony tekst nie woła Jev drugi raz (pamięć podręczna werdyktu). To demo w dobrej wierze, nie usługa bez limitu.

BYOK

Własne proxy: cd server, npm install, npm start. W opcjach wpisz http://127.0.0.1:8787. Klucz wstawiasz tylko w server/.env.

Tekst wysyłany do Jev jest obcięty do 6000 znaków. Opcjonalny dobowy limit IP włączysz zmienną EVALUATE_DAILY_IP_CAP.

Prywatność w skrócie

Na proxy idzie identyfikator posta, tekst (do 6000 znaków) i opcjonalnie imię z karty. Proxy nie zapisuje treści postów na dysk. W pamięci trzyma skrót znormalizowanego tekstu i werdykt, z czasem życia, oraz licznik żądań na IP. Rozszerzenie w storage przeglądarki (storage.sync, a gdy sync nie działa, storage.local) trzyma tylko włącznik, próg i adres proxy. Szczegóły: polityka prywatności i regulamin.
