LinkedIn AI Slop

Rozszerzenie do Chrome i Edge. Przy scrollowaniu feedu LinkedIn na karcie pojawia się odznaka. Kod jest publiczny: github.com/pawelmamcarz/linkedin-ai-slop.

  • Ludzki

Co to jest

Gdy post wejdzie w widok (około 35% wysokości kadru), rozszerzenie wyciąga jego tekst i prosi o ocenę. Odznaka ląduje w prawym górnym rogu karty. Komentarze pod postem są pomijane, a tekst krótszy niż 40 znaków w ogóle nie wychodzi z przeglądarki.

TypeSafe Jev

Ocena idzie przez TypeSafe Jev API: POST https://api.typesafe.ai/v1/systemone, model jev-latest. Jedno wywołanie na post, cztery pytania: is_ai_slop, slop_intensity, has_substance, voice.

Kolor odznaki liczy kod w repozytorium (jev/thresholds.ts), nie ta strona. Domyślny próg is_ai_slop to 0.65.

Instalacja z repozytorium

Możesz załadować katalog extension/ z publicznego repozytorium albo paczkę store/linkedin-ai-slop-extension.zip (npm run pack:extension).

  1. Pobierz github.com/pawelmamcarz/linkedin-ai-slop.
  2. Otwórz chrome://extensions (w Edge: edge://extensions) i włącz tryb dewelopera.
  3. Wybierz Załaduj rozpakowane i wskaż katalog extension/ (albo rozpakowany zip).
  4. W opcjach włącz ocenę. Domyślny adres proxy to https://proxy-production-ebcc.up.railway.app. Przycisk Sprawdź proxy powinien pokazać model jev-latest.

Hostowane proxy i własny klucz

Domyślne proxy jest na Railway. Klucz TYPESAFE_API_KEY zostaje po stronie serwera. Ta strona go nie ma i sama nie woła TypeSafe. Własne proxy jest opcjonalne: cd server, potem npm install i npm start, a w opcjach rozszerzenia adres http://127.0.0.1:8787. GitHub Pages serwuje tylko pliki z docs/.

Publiczne POST /evaluate przyjmuje do 60 żądań na minutę z jednego adresu IP, żeby demo nie wypaliło klucza.
