LinkedIn AI Slop

Odznaka na karcie posta, gdy scrollujesz feed: Ludzki, Mieszany albo AI slop. Ocena idzie przez TypeSafe Jev. Klucz API nie trafia do rozszerzenia.

Zainstaluj z GitHub Zobacz demo Autor: mamcarz.com

Hostowane proxy to publiczne demo z limitem. Do codziennej pracy postaw własne proxy i własny klucz (BYOK). Sklep Chrome jeszcze nie jest źródłem instalacji. Ta sama paczka zip działa w Chrome, Brave i Edge. Firefox to osobny XPI (dodatek tymczasowy, bez listy AMO). Safari to build na Macu, bez App Store. Produkt działa tylko na LinkedIn.

Jak to działa

1. Widoczny post

Gdy karta wejdzie w widok (około 35% wysokości), rozszerzenie bierze tekst posta. Komentarze pomija. Tekst krótszy niż 40 znaków zostaje w przeglądarce.

2. Jev na proxy

Jedno wywołanie na post: model jev-latest, pytania is_ai_slop, slop_intensity, has_substance, voice. Próg domyślny to 0.65.

3. Odznaka

Kolor liczy kod w repozytorium, nie ta strona. Najedź na odznakę, żeby zobaczyć prawdopodobieństwa.

Suwak progu

Model daje każdemu postowi ocenę od 0 do 1. To szansa, że tekst brzmi jak AI slop. Bliżej 1 sygnał jest mocniejszy. Odznaka „AI slop” pojawia się, gdy ocena jest równa progowi albo wyższa. Suwak w opcjach rozszerzenia chodzi od około 0.15 do 0.95. Domyślnie stoi koło 0.65.

Niżej, czulej

Próg 0.15 łapie słabszy sygnał. Więcej kart dostaje odznakę „AI slop”.

Domyślnie 0.65

To punkt startowy. Ustawiasz go sam w opcjach rozszerzenia, obok włącznika i trybu.

Wyżej, ostrzej

Próg 0.95 puszcza tylko mocny sygnał. Rzadziej zobaczysz „AI slop”, częściej „Ludzki” albo „Mieszany”.

Instalacja

Chrome i Edge

  1. Pobierz repozytorium albo rozpakuj store/linkedin-ai-slop-extension.zip.
  2. Otwórz chrome://extensions albo edge://extensions i włącz tryb dewelopera.
  3. Załaduj rozpakowane i wskaż katalog extension/.

Sklep Chrome jeszcze nie publikuje tej pozycji. Zip odtwarzasz przez npm run pack:extension.

Brave

Ta sama paczka Chromium. Osobnego pliku Brave nie ma.

  1. Otwórz brave://extensions i włącz tryb dewelopera.
  2. Załaduj rozpakowane i wskaż extension/.
  3. Gdy sklep Chrome ruszy, Brave umie wziąć stamtąd ten sam wpis. Dziś go nie ma.

Notatka: store/BRAVE.md.

Firefox

Osobny XPI, te same skrypty. Firefox 142+. Listy na addons.mozilla.org nie ma.

  1. npm run pack:firefox składa store/linkedin-ai-slop-firefox.xpi.
  2. Otwórz about:debugging#/runtime/this-firefox.
  3. Załaduj dodatek tymczasowy i wskaż ten XPI. Po restarcie Firefoksa zrób to ponownie.

Notatka: store/FIREFOX.md.

Safari

Projekt Xcode w safari/. Na Macu: bash scripts/build-safari.sh. To nie jest App Store ani TestFlight.

  1. Safari → Develop → Allow Unsigned Extensions.
  2. Uruchom aplikację z Xcode, włącz rozszerzenie i zezwól na www.linkedin.com.

Notatka: store/SAFARI.md.

Przejdź do Pro

Proxy demo i własny klucz

Publiczne demo

https://proxy-production-ebcc.up.railway.app

Klucz TYPESAFE_API_KEY zostaje na serwerze. Ta strona go nie ma i sama nie woła TypeSafe. GitHub Pages serwuje tylko docs/.

Limit: 60 żądań na minutę z jednego adresu IP. Powtórzony tekst nie woła Jev drugi raz (pamięć podręczna werdyktu). To demo w dobrej wierze, nie usługa bez limitu.

BYOK

Własne proxy: cd server, npm install, npm start. W opcjach wpisz http://127.0.0.1:8787. Klucz wstawiasz tylko w server/.env.

Tekst wysyłany do Jev jest obcięty do 6000 znaków. Opcjonalny dobowy limit IP włączysz zmienną EVALUATE_DAILY_IP_CAP.

Prywatność w skrócie

Na proxy idzie identyfikator posta, tekst (do 6000 znaków) i opcjonalnie imię z karty. Proxy nie zapisuje treści postów na dysk. W pamięci trzyma skrót znormalizowanego tekstu i werdykt, z czasem życia, oraz licznik żądań na IP. Rozszerzenie w storage przeglądarki (storage.sync, a gdy sync nie działa, storage.local) trzyma włącznik, próg, tryb, adres proxy i opcjonalny token Pro. Klucza TypeSafe tam nie ma.
